1. Introduction                                         *bufpanel* *bufpanel-intro*

bufpanel.nvim ouvre à gauche un panneau en deux sections :

  - BUFFERS : les buffers ouverts, dans l'ordre de leur première ouverture.
  - RÉCENTS : les fichiers ouverts dernièrement sous le répertoire de travail
    courant, du plus récent au plus ancien. Section repliable.

`▎` marque le buffer courant, `●` un buffer modifié.

Neovim 0.10 minimum. `nvim-web-devicons` est optionnel.

==============================================================================
2. Configuration                                             *bufpanel-config*

>lua
    require("bufpanel").setup({
      width = 32,
      open_on_startup = true,
      min_columns = 0,       -- 0 = sans limite
      startup_exclude_filetypes = { "gitcommit", "gitrebase" },
      icons = true,
      show_help = true,
      close_on_filetypes = {}, -- voir |bufpanel-autoclose|
      reopen_after = true,
      recent = {
        visible = true,    -- section dépliée au démarrage
        max_display = 15,  -- entrées affichées
        max_stored = 50,   -- entrées conservées par cwd
      },
      keymaps = {          -- `false` désactive un raccourci
        open = "<CR>",
        close_buffer = "x",
        toggle_recent = "R",
        close_panel = "q",
      },
    })
<
Le panneau ne s'ouvre pas au démarrage en mode diff, en mode headless, ni si
le filetype du buffer initial est dans `startup_exclude_filetypes`. Il
s'ouvre sans prendre le focus.

Si `min_columns` est supérieur à 0 et que Neovim fait moins de colonnes
(`'columns'`), les ouvertures automatiques (démarrage, réouverture après
|bufpanel-autoclose|) sont ignorées. Les commandes |:BufPanelOpen|,
|:BufPanelToggle| et |:BufPanelFocus| ouvrent toujours le panneau.

==============================================================================
3. Commandes                                               *bufpanel-commands*

:BufPanelOpen                                                  *:BufPanelOpen*
    Ouvre le panneau dans l'onglet courant.

:BufPanelClose                                                *:BufPanelClose*
    Ferme le panneau.

:BufPanelToggle                                              *:BufPanelToggle*
    Ouvre ou ferme le panneau.

:BufPanelFocus                                                *:BufPanelFocus*
    Ouvre le panneau si nécessaire et y place le curseur.

Aucun raccourci global n'est créé.

==============================================================================
4. Raccourcis du panneau                                    *bufpanel-keymaps*

<CR>    Ouvre l'entrée dans la dernière fenêtre d'édition. Sur l'en-tête
        RÉCENTS : déplie ou replie la section.
x       Ferme le buffer sous le curseur sans fermer ses fenêtres. Refusé si
        le buffer est modifié. Sans effet dans les récents.
R       Déplie ou replie la section RÉCENTS.
q       Ferme le panneau.

==============================================================================
5. Fermeture automatique                                  *bufpanel-autoclose*

`close_on_filetypes` liste des filetypes dont l'ouverture d'une fenêtre dans
l'onglet courant ferme le panneau. Les fenêtres flottantes comptent
aussi. >lua
    opts = {
      close_on_filetypes = { "neo-tree", "NvimTree", "fugitive" },
    },
<
Le filetype d'un plugin s'obtient avec `:set ft?` dans sa fenêtre. Les
plugins qui s'ouvrent dans un nouvel onglet (Diffview) n'ont pas besoin d'être
listés.

Avec `reopen_after = true`, le panneau se rouvre sans prendre le focus quand
ces fenêtres sont toutes fermées et qu'il reste une fenêtre d'édition.

Une fermeture manuelle (|:BufPanelClose|, |:BufPanelToggle|, `q`) annule la
réouverture. Une ouverture manuelle pendant qu'une de ces fenêtres est ouverte
est respectée jusqu'à l'apparition d'une nouvelle fenêtre de la liste.

Au démarrage, si une de ces fenêtres est déjà ouverte (`nvim .` avec
neo-tree), le panneau ne s'ouvre qu'à sa fermeture.

==============================================================================
6. Historique                                               *bufpanel-history*

L'historique est rangé par répertoire de travail global (|:pwd|) et stocké
dans : >
    stdpath("data") .. "/bufpanel/history.json"
<
Il est écrit peu après chaque changement et à la sortie de Neovim, en
fusionnant avec le contenu du fichier pour ne pas écraser ce qu'une autre
instance a écrit. Pour le réinitialiser, quitter Neovim et supprimer le
fichier.

==============================================================================
7. Surbrillance                                          *bufpanel-highlights*

Groupes définis avec `default = true` :

  BufPanelHeader          -> Title
  BufPanelCurrent         -> Directory
  BufPanelCurrentMarker   -> Special
  BufPanelModified        -> DiagnosticWarn
  BufPanelDir             -> Comment
  BufPanelHelp            -> Comment
